# S-Plane Timing Dataset Datasheet

Synthetic labelled dataset generated by a deterministic pure-Python PTP/SyncE clock-servo simulator.

Rows: 3420

Label counts: {'healthy': 2168, 'H0': 715, 'H1': 537}

Labels: `healthy`, `H0` benign timing fault, `H1` timing attack.

Limitations: no hardware timestamping, no real O-RU/O-DU, no production traffic. The dataset is intended for reproducible research prototyping and resume/demo evidence, not certification.
